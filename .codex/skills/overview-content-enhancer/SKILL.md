# Overview Content Enhancer

## 出力
- `doc/01_overview/project-brief.md`
- `doc/01_overview/goals-non-goals.md`
- `doc/01_overview/scope.md`
- `doc/01_overview/glossary.md`

## 手順
1. 既存の `doc/01_overview` 4ファイルを読み、薄い記述・矛盾・未定義語を洗い出す。
2. `project-brief.md` を加筆し、対象ユーザー、課題、価値仮説、成功条件を具体化する。
3. `goals-non-goals.md` を加筆し、測定可能な目標と非対象を明確化する。
4. `scope.md` を加筆し、in/out境界と判断基準を追記する。
5. `glossary.md` を加筆し、頻出語の定義と禁止語（曖昧語）を整理する。
6. 4ファイル間で語彙と主張の整合を確認して仕上げる。

## 判断ポイント（ユーザー確認）
1. 目的とゴールの具体化確認
- 進行条件: 目標値または判定基準が合意される。

2. スコープ境界確認
- 進行条件: in/out が実務判断に使える粒度で合意される。

3. 用語統一確認
- 進行条件: 関係者間で誤読が起きない定義になっていると合意される。

## 完了条件
- `doc/01_overview` の4ファイルが加筆更新されている。
- 4ファイル間に矛盾がない。
- 後続工程が迷わない判断基準が明文化されている。
