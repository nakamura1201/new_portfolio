# Design Visual Direction Brief

## 入力
- `doc/01_overview/project-brief.md`
- `doc/01_overview/goals-non-goals.md`
- `doc/02_requirements/text.md`
- `doc/03_spec/text.md`
- 必要に応じて既存ブランド資料

## 出力
- `doc/04_design/figma-handoff/design-visual-direction.md`

## 手順
1. プロダクトの目的と対象ユーザーから、ブランド印象キーワードを3-5個に絞る。
2. 参考トーン（近い/避けたい）を定義し、見た目の方向性を言語化する。
3. 配色方針、タイポ方針、余白密度、アイコン/イラスト方針を定義する。
4. 禁止事項（やらない表現）を明示し、デザイン判断のブレを防ぐ。

## 判断ポイント（ユーザー確認）
1. トーン妥当性確認
- 進行条件: キーワードと参照トーンが承認される。

2. 表現制約確認
- 進行条件: 禁止事項と許容範囲が承認される。

## 完了条件
- Figma担当者が迷わず再現できるテイスト指示が1ファイルで定義されている。
