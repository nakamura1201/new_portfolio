# SNS Step 3 投稿制作

## 出力
- `doc/05_marketing/03_sns_marketing/step-03-投稿制作/制作ガイド.md`
- `doc/05_marketing/03_sns_marketing/step-03-投稿制作/投稿カレンダー.md`
- `doc/05_marketing/03_sns_marketing/step-03-投稿制作/品質チェックリスト.md`

## 手順
1. 投稿フォーマット（短文/画像/動画/スレッド）を定義する。
2. 週次または月次の投稿カレンダーを作成する。
3. 制作フローと公開前チェック項目を定義する。

## 完了条件
- 投稿頻度、担当、品質基準が運用可能な粒度で記述されている。
