# 追加Step リリース計画

## 出力
- `doc/05_marketing/01_product_marketing/step-15-リリース計画/リリース計画.md`
- `doc/05_marketing/01_product_marketing/step-15-リリース計画/マイルストーン.md`
- `doc/05_marketing/01_product_marketing/step-15-リリース計画/ロールバック計画.md`

## 手順
1. リリースを段階（クローズドβ/限定公開/一般公開など）で定義する。
2. マイルストーンと担当、期限、依存関係を整理する。
3. 失敗時のロールバック条件と運用手順を記述する。

## 完了条件
- リリース判断基準と責任者が明記されている。
- 実行可能なスケジュールとリスク対応が揃っている。
