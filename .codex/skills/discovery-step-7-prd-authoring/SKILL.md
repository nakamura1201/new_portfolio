# Step 7 PRD作成

## 出力
- `doc/05_marketing/01_product_marketing/step-14-PRD作成/PRDドラフト.md`
- `doc/03_spec/text.md`
- `doc/02_requirements/text.md`

## 手順
1. 背景と目的を検証結果ベースで記述する。
2. ユーザーストーリーを確定する。
3. 機能要件と拡張候補を切り分ける。
4. 非機能要件とKPIを定義する。
5. 事業性（獲得チャネル・収益仮説・主要リスク）を記述する。

## 完了条件
- 実装チームが迷わず着手できるPRD品質になっている。
- 事業面の継続可能性がPRD内で説明されている。
