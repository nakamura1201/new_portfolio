# 追加Step 検証設計

- `doc/02_research/検証計画.md`
- `doc/02_research/インタビュー質問票.md`

## 手順
1. 検証したい仮説を優先順で並べる。

3. 成功/失敗判定基準を先に固定する。
4. インタビュー質問票を作成する。
