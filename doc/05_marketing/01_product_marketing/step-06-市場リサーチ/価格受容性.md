# 価格受容性

最終更新: 2026-04-07

## 前提
- 本件は「自分のポートフォリオを運用し、採用/案件機会を獲得する」モデル。
- 価格受容性はツール費用と制作外注費用の2軸で評価する。

## 段階価格（低/中/高）

## 1. 低価格帯（0〜1,000円/月）
- 想定手段: GitHub Pages、無料プラン、STUDIO最小プラン近辺
- 受容理由:
  - 初期コストを最小化できる
  - 検証段階で試しやすい
- 拒否理由:
  - 機能制限や運用上限
  - 表現や拡張に制約

## 2. 中価格帯（1,000〜5,000円/月）
- 想定手段: STUDIO上位、Wix/WordPress有料帯、独自ドメイン運用
- 受容理由:
  - 独自ドメインや解析導入で信頼性が上がる
  - 継続運用での実務価値が高い
- 拒否理由:
  - 受注/採用成果が出る前は割高に感じやすい

## 3. 高価格帯（5,000円/月超 または制作外注5万〜40万円）
- 想定手段: 制作外注、継続改善込み運用
- 受容理由:
  - 時間節約と品質担保
  - 非エンジニア層には有効
- 拒否理由:
  - 個人エンジニアの自己投資としては回収不確実

## 推奨価格方針（本プロジェクト）
- 初期は低〜中価格帯で開始し、成果（面談化率、問い合わせ率）に応じて増額。
- 目安: 月額 1,500〜3,000円 + 年間ドメイン費。

## 価格受容性の検証仮説
- PH-01: 1,000円未満では導入障壁がほぼない
- PH-02: 3,000円前後までは成果連動で受容される
- PH-03: 高価格帯は「時間短縮」ニーズが明確な場合のみ成立
