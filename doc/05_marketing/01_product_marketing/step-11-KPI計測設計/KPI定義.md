# KPI定義

最終更新: 2026-04-08

## 北極星指標（NSM）
- NSM-01: 判断完了セッション率
- 定義: 「初回訪問で実績詳細閲覧後に、問い合わせ導線到達または面談候補判断完了したセッション」の割合
- 目標: 35%以上

## 補助KPI

## 1. 価値理解KPI
- KPI-01: ファーストビュー理解達成率
  - 定義: 30秒以内に専門領域を理解できた割合
  - 目標: 80%以上

## 2. 実績証拠KPI
- KPI-02: 実績詳細読了率
  - 定義: 実績詳細で主要セクション（課題/担当範囲/実装/成果/技術）を読了した割合
  - 目標: 70%以上

- KPI-03: 3分判断達成率
  - 定義: 実績詳細到達から180秒以内に判断行動（CTA到達/判断完了）した割合
  - 目標: 70%以上

## 3. 導線KPI
- KPI-04: CTA到達率
  - 定義: セッション内でCTAが1回以上視認+クリックされた割合
  - 目標: 80%以上

- KPI-05: 問い合わせ意向率
  - 定義: 問い合わせ導線クリックまたは面談希望表明割合
  - 目標: 50%以上

## 4. 品質KPI
- KPI-06: モバイル導線成功率
  - 定義: 375px幅で主要導線（実績詳細→CTA）完了した割合
  - 目標: 75%以上

## Go/No-Go閾値
- Go:
  - NSM-01 >= 35%
  - KPI-03 >= 70%
  - KPI-04 >= 80%
- Conditional Go:
  - NSM-01 25〜34% かつ 改善施策で2週間以内に回復可能
- No-Go / Pivot:
  - NSM-01 < 25% または KPI-03 < 50%

## 先行指標 / 遅行指標
- 先行指標: KPI-01, KPI-04
- 遅行指標: NSM-01, KPI-05
