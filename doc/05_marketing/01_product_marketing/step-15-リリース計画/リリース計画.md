# リリース計画

最終更新: 2026-04-10

## リリース方針
- 方針: 段階リリース（Closed Beta -> Limited Release -> General Availability）
- 目的: KPI-01/KPI-04未達リスクを抑えながら、検証を継続して公開品質を高める。

## 段階定義
### Phase 1: Closed Beta
- 対象: 既知の評価者 10〜20名
- 目的: 30秒理解、3分判断、CTA到達の初期検証
- 進行条件:
  - KPI-03 >= 70%
  - 致命障害（フォーム不達、ページ崩壊）なし

### Phase 2: Limited Release
- 対象: 履歴書/SNS経由の限定公開
- 目的: 実流入でNSM-01と問い合わせ意向率を検証
- 進行条件:
  - NSM-01 >= 30%
  - KPI-04 >= 75%
  - 重大リスク R-01/R-03/R-04 の一次対策完了

### Phase 3: General Availability
- 対象: 一般公開
- 目的: Go条件（NSM-01 >= 35%、KPI-03 >= 70%、KPI-04 >= 80%）の安定運用
- 進行条件:
  - 2週連続で主要KPI閾値を満たす
  - 運用SLA（問い合わせ48h以内）が成立

## リリース判定責任
- 判定責任者: Owner（あなた）
- 判定材料:
  - KPIダッシュボード週次値
  - リスク台帳の重大リスク状況
  - 問い合わせ運用SLA達成状況

## 依存条件
1. PRD正本・要件正本の凍結
2. 計測イベント（EV-01〜10）実装
3. 法務確認事項の公開前チェック完了
