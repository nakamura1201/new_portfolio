## 重点影響分析
### 1. 要件への影響（高）
- FR/NFRをMVP優先に再編し、`doc/02_requirements/text.md` を正本化。
- KPI連動要件を追加し、受け入れ判定を数値化。

### 2. 仕様への影響（高）
- `doc/03_spec/text.md` に画面・計測・受け入れ条件を統合。
- 実績テンプレ必須5項目を仕様固定。

### 3. 計画への影響（高）
- 段階リリース（Closed Beta -> Limited -> GA）を採用。
- ロールバック発動条件と責任体制を定義。

### 4. 実装への影響（高）
- 実装優先順位を `M-01 -> M-02 -> M-03 -> M-04 -> M-05` に固定。
- 実装着手前の前提条件:
  1. KPI-01/KPI-04改善施策の反映
  2. 重大リスク一次対策（R-01/R-03/R-04）
  3. 計測イベントEV-01〜10の実装可能性確認
