# 機能要件一覧

最終更新: 2026-04-07

## FR-001: トップページ表示
- **概要**: 自己紹介、強み、主要導線を表示する。
- **詳細**: ファーストビューに氏名または屋号、職種、主要CTAを表示し、実績一覧と問い合わせ導線へ遷移できること。
- **関連画面**: トップページ
- **優先度**: 高
- **acceptance-criteria**: ページ読み込み後3秒以内にファーストビューが表示され、`実績を見る` と `問い合わせる` の2導線が視認できること。

## FR-002: 実績一覧表示
- **概要**: 実績カードを一覧で表示する。
- **詳細**: 各カードに案件名、概要、使用技術、詳細ページへのリンクを表示する。
- **関連画面**: 実績一覧ページ
- **優先度**: 高
- **acceptance-criteria**: 実績データ3件以上がカード形式で表示され、各カードから対応する実績詳細ページへ遷移できること。

## FR-003: 実績詳細表示
- **概要**: 実績ごとの詳細情報を表示する。
- **詳細**: 課題、担当範囲、実装内容、成果、使用技術を表示する。
- **関連画面**: 実績詳細ページ
- **優先度**: 高
- **acceptance-criteria**: 任意の実績詳細ページで「課題」「担当範囲」「実装内容」「成果」「使用技術」の5項目が欠落なく表示されること。

## FR-004: スキル一覧表示
- **概要**: 技術スキルをカテゴリ別に表示する。
- **詳細**: 言語、フレームワーク、ツールをカテゴリで分け、経験レベルを表示する。
- **関連画面**: トップページまたはスキルセクション
- **優先度**: 中
- **acceptance-criteria**: 3カテゴリ以上が表示され、各カテゴリに1件以上のスキル項目が表示されること。

## FR-005: 問い合わせ導線
- **概要**: ユーザーが1クリックで連絡手段に到達できる。
- **詳細**: ヘッダーまたは固定CTAからメールリンクまたはフォームへの遷移を提供する。
- **関連画面**: 全ページ共通
- **優先度**: 高
- **acceptance-criteria**: 全ページで問い合わせ導線が表示され、クリック後に連絡手段へ遷移できること。

## FR-006: レスポンシブ表示
- **概要**: 主要画面をモバイル/タブレット/PCで最適表示する。
- **詳細**: 崩れのないレイアウトと操作可能なナビゲーションを提供する。
- **関連画面**: 全ページ
- **優先度**: 高
- **acceptance-criteria**: 375px、768px、1280pxの各幅で横スクロールが発生せず、主要導線が操作可能であること。
