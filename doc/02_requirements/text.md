# 要件定義正本

最終更新: 2026-04-08

## 1. 要件方針
- functional / non-functional を分離
- acceptance-criteria は OK/NG 判定可能な表現で記述

## 2. 機能要件（MVP）
### FR-001 ファーストビュー価値訴求
- 要件: 職種・専門領域・CTAを初期表示
- acceptance-criteria: 初回表示30秒以内に専門領域を説明できるユーザーが80%以上

### FR-002 実績一覧表示
- 要件: 代表実績3件以上を表示
- acceptance-criteria: 実績カードから詳細遷移成功率が95%以上

### FR-003 実績詳細証拠テンプレート
- 要件: 課題/担当範囲/実装/成果/技術の必須5項目を表示
- acceptance-criteria: 全実績で5項目欠落なし（100%）

### FR-004 全ページCTA統一
- 要件: ヘッダー/フッター/主要セクションでCTA統一
- acceptance-criteria: CTA到達率80%以上

### FR-005 問い合わせ導線
- 要件: 1クリックで連絡手段へ遷移
- acceptance-criteria: 問い合わせ導線クリック後の到達率95%以上

### FR-006 レスポンシブ導線品質
- 要件: 375/768/1280で主要導線が機能
- acceptance-criteria: 横スクロール無し、主要導線成功率75%以上

## 3. 非機能要件
### NFR-001 パフォーマンス
- 基準: 初回主要表示3秒以内

### NFR-002 セキュリティ
- 基準: XSS対策（出力エスケープ、入力バリデーション）

### NFR-003 アクセシビリティ
- 基準: キーボードで主要導線へ到達可能

### NFR-004 計測信頼性
- 基準: イベント欠損率5%未満

## 4. KPI連動要件
- NSM-01 >= 35%
- KPI-01 >= 80%
- KPI-03 >= 70%
- KPI-04 >= 80%
- KPI-05 >= 50%

## 5. 非対象（非MVP）
- CMS、多言語、会員機能、ブログ、高度分析ダッシュボード
