# Design Visual Direction

最終更新: 2026-04-20

## 1. このプロダクトで与えたい印象
- 洗練されている
- モダン
- 信頼できる
- 実務的
- 安っぽくない

## 2. デザインの基本姿勢
- 採用担当者・エンジニアリングマネージャー・クライアントが、3分以内に「何ができるか」を判断できる情報密度を優先する。
- 装飾で魅せるより、見出し、数行の要約、実績証拠、CTAの視認性で評価判断を支える。
- 見た目は静的で固くしすぎず、現代的で上質なプロダクト感を持たせる。
- 派手さで目を引くのではなく、余白、整列、タイポ、素材感の統一で洗練を出す。

## 3. 参考トーン
### 3.1 近いトーン
- 洗練されたプロダクトサイトのような、静かで上質な画面
- モダンなSaaSサイトのような、整理された情報設計
- 余白とタイポで魅せるエディトリアル寄りの構成

### 3.2 避けたいトーン
- 安価なテンプレート感が強いUI
- クリエイティブ優先で情報の意味が後退する表現
- ゲーム風、近未来風、グロー過多など演出が主役のUI
- 余白不足でカードやテキストが詰まって見えるレイアウト
- 配色コントラスト不足でCTAや見出しが埋もれる表現

## 4. 配色方針
- ベースは明るい背景を基本とし、本文可読性を最優先する。
- 主役色は 1 色に絞り、CTA、リンク、アクティブ状態、注目ラベルに限定して使う。
- サブ色は中立グレー中心で構成し、カード境界、補助情報、区切りに使う。
- 実績詳細やスキルでは、色数を増やさず構造差をタイポと余白で見せる。
- コントラストは AA 相当を満たし、淡色の上に淡色テキストは置かない。
- 彩度の高すぎる色や、既視感の強い派手配色は避ける。

## 5. タイポグラフィ方針
- 見出しは「判断を早めるラベル」として短く強く扱う。
- 本文は長文化させず、1ブロック 3 行前後で読み切れる密度を目安にする。
- 数字、技術タグ、成果指標は本文に埋めず、視線停止しやすい見せ方にする。
- フォント選定は、装飾性よりも和文可読性と英数字の整然さを優先し、チープな印象の書体は避ける。

## 6. レイアウト方針
- 375px / 768px / 1280px の 3 段階で、主要導線が視線の自然な流れに乗る構造にする。
- 1280px では情報を横に広げすぎず、本文行長を制御する。
- 実績カードと実績詳細は、情報の階層が一目で分かる区切りを持たせる。
- セクション間は 4px 基準トークンで組み、狭い画面でも圧迫感を出さない。

## 7. コンポーネント別の見せ方
### 7.1 Header
- 常に主要CTAへ到達しやすい、簡潔で固定的な印象。
- scrolled 状態では情報を圧縮しつつ、CTAの存在感は維持する。

### 7.2 CTA Button / Contact Link
- 第一CTAは即時に識別できる強さを持たせる。
- Secondary は補助導線として十分な存在感を保ちつつ、Primary を食わない。
- Text link でも hover / focus で確実にインタラクションを認識できる見た目にする。

### 7.3 Project Card / Project Detail
- 案件名、概要、技術タグ、詳細導線の順に、短時間で意味が通る構成にする。
- 成果や担当範囲は装飾よりラベル整理で信頼感を出す。

### 7.4 Skill Category
- 自己申告感を弱め、整理された能力一覧として見せる。
- 習熟度表現は過剰にゲーム化せず、年数または簡潔な熟達表現を優先する。

## 8. アイコン・図版方針
- アイコンは補助用途に限定し、意味がラベル無しで伝わらないものは使わない。
- イラストや写真は必須ではない。入れる場合も情報理解を妨げない軽さに抑える。
- 技術タグや成果ラベルは、アイコンよりテキストの明快さを優先する。
- 素材を入れる場合は、質感やレンダリングの甘さで安っぽく見えないことを優先する。

## 9. 禁止事項
- ガラスモーフィズム、過度なぼかし、強いネオン、過剰なグラデーション
- 安価なLPテンプレートのような、装飾過多の見た目
- 文字ジャンプや不規則配置で可読性を落とすレイアウト
- CTA以外を主役に見せる強い装飾
- 見出しやタグの意味を薄める抽象的な英語コピー多用
- 実績の証拠情報より先にビジュアル演出が目に入る構成

## 10. Figma担当者への補足
- このサイトは「作品展示」より「判断支援」が目的。
- 各画面・各コンポーネントで、最初に目に入るべき要素が CTA か証拠情報かを明確に設計する。
- トークン化前提で、color / typography / spacing / radius が横断利用しやすい粒度で整理する。
