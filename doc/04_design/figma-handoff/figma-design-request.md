# Figma Design Request

最終更新: 2026-04-13

## 1. プロジェクト背景
- プロジェクト名: 証拠型ポートフォリオサイト（MVP）
- 目的: 採用担当者・エンジニアリングマネージャー・クライアントが、初回訪問3分以内にスキル適合性と依頼可否を判断できるようにする。
- ゴール:
  - 初回訪問30秒以内に「職種」「専門領域」「主要CTA」が理解できること
  - 実績詳細で「課題」「担当範囲」「実装内容」「成果」「使用技術」の5項目を欠落なく提示すること
  - 主要導線「トップ -> 実績詳細 -> 問い合わせ」をモバイル/PCで成立させること
- 非ゴール:
  - CMS導入
  - 多言語対応
  - 会員/ログイン機能
  - ブログ運用機能
  - 高度な分析ダッシュボード

## 2. ターゲット
- 想定ユーザー:
  - 採用担当者
  - エンジニアリングマネージャー
  - 制作依頼前のクライアント
- 利用シーン:
  - 面談前の事前評価（3分程度）
  - 依頼前の実務適合性確認（SNS/履歴書から遷移）
- 主要課題:
  - 評価材料が分散し、初回接触で判断に必要な情報が不足する
  - 見た目中心の紹介になり、課題解決力や実装意図が伝わりにくい

## 3. 依頼内容
- 対象画面:
  - トップページ
  - 実績一覧ページ
  - 実績詳細ページ
  - 問い合わせ導線（ヘッダー/フッター/主要セクション）
- 画面ごとの目的:
  - トップ: 30秒理解達成（職種・専門領域・2つのCTAの明示）
  - 実績一覧: 代表実績3件以上を比較し、詳細遷移につなげる
  - 実績詳細: 5項目テンプレートで3分判断を可能にする
  - 問い合わせ導線: 1クリックで連絡手段へ遷移させる
- 必須機能:
  - 全ページCTA統一配置
  - 実績カードから詳細遷移
  - 実績詳細の必須5項目表示
  - 返信目安テキストの表示
- 必須コンポーネント:
  - Header / Navigation
  - CTA Button
  - Project Card
  - Project Detail Sections
  - Skill Category Block
  - Footer

## 4. デザイン要件
- トーン&マナー: 信頼感、実務的、情報優先、過剰装飾を避ける
- 配色方針: 可読性とコントラストを優先した配色（ブランドカラーは未確定のため提案付きで提示）
- タイポグラフィ方針: 長文可読性を優先し、見出しと本文の階層を明確化
- 余白・グリッド方針: デスクトップは12カラム基準、モバイルは1カラム基準
- レスポンシブ要件: 375px / 768px / 1280px の3ブレークポイントで導線破綻なし
- アクセシビリティ要件:
  - キーボード操作で主要導線へ到達可能
  - フォーカス可視化
  - テキストと背景のコントラスト確保（AA相当）
- 状態変化（hover/active/error/loading/disabled）:
  - ボタン、カード、フォーム要素（必要時）で状態差分を定義

## 5. 成果物要件
- Figmaページ構成:
  - 00_cover
  - 01_wireframe
  - 02_ui
  - 03_components
  - 04_handoff
- コンポーネント命名規則: `cmp/{category}/{name}/{variant}`
- バリアント設計:
  - size（sm/md/lg）
  - state（default/hover/active/focus/disabled）
  - breakpoint（mobile/tablet/desktop）
- Dev handoffに必要な注釈:
  - spacing / size / radius / color / typography token
  - interaction差分（duration, easing）
  - 各画面の実装優先順位

## 6. 制約・前提
- 技術制約:
  - 既存サイト実装（PHPテンプレート + CSS/JS）に組み込み可能な構造にする
  - 初期リリースはMVP範囲のみ
- 実装優先度:
  - 実績証拠化（詳細5項目） > CTA統一導線 > FV最適化 > スキルセクション視認性
- 締切:
  - 未確定（`open-questions.md` Q-01で確定）

## 8. 最終依頼文（貼り付け用）
以下の要件で、MVP向けポートフォリオサイトのFigmaデザインを作成してください。

目的は「採用/発注判断者が3分以内に実務適合性を評価できること」です。対象画面はトップ、実績一覧、実績詳細、問い合わせ導線です。トップでは30秒以内に職種・専門領域・CTAが理解できる構成にしてください。実績一覧は3件以上の案件カードを表示し、実績詳細では「課題」「担当範囲」「実装内容」「成果」「使用技術」の5項目を必須で設計してください。CTAはヘッダー/フッター/主要セクションで統一し、1クリックで連絡手段に到達できる必要があります。

デザインは信頼感と可読性を重視し、レスポンシブ（375/768/1280）とアクセシビリティ（キーボード操作、フォーカス可視化、十分なコントラスト）を満たしてください。コンポーネントは命名規則 `cmp/{category}/{name}/{variant}` で整理し、状態（default/hover/active/focus/disabled）とブレークポイント差分をバリアント化してください。handoffにはトークン（spacing, color, typography など）とインタラクション注釈を含めてください。
