# Figma Design Request

最終更新: 2026-04-10

## 1. プロジェクト背景
- プロジェクト名: Frontend Engineer Portfolio (MVP)
- 目的: 3分以内で実務適合性を判断できる証拠型ポートフォリオを構築する。
- ゴール:
  - 30秒で専門領域を理解できるFV
  - 実績詳細で課題/担当範囲/実装/成果/技術を明確提示
  - 1クリックで問い合わせ導線へ到達
- 非ゴール:
  - CMS、多言語、会員機能、ブログ、高度分析ダッシュボード

## 2. ターゲット
- 想定ユーザー:
  - エンジニアリングマネージャー
  - 採用担当
  - 外注判断者
- 利用シーン: 面談前・相談前の短時間評価（3〜5分）
- 主要課題: 証拠不足、導線不足、初見理解不足

## 3. 依頼内容
- 対象画面:
  1. トップ
  2. 実績一覧
  3. 実績詳細
  4. 問い合わせセクション
- 画面ごとの目的:
  - トップ: 30秒理解
  - 実績一覧: 比較可能性
  - 実績詳細: 3分判断
  - 問い合わせ: 1クリック連絡
- 必須機能:
  - 全ページCTA統一
  - 実績3件以上
  - 実績詳細必須5項目
- 必須コンポーネント:
  - Header/Nav
  - CTA Button
  - Project Card
  - Project Detail Block
  - Skill Block
  - Footer + PageTop

## 4. デザイン要件
- トーン&マナー: 信頼感、実務的、過剰装飾なし
- 配色方針: 白/淡色ベース + 青系アクセント
- タイポグラフィ方針: 可読性優先、見出しは太め
- 余白・グリッド方針: 12カラム基準、モバイルは1カラム
- レスポンシブ要件: 375 / 768 / 1280
- アクセシビリティ要件: コントラスト確保、キーボード導線、フォーカス可視化
- 状態変化: hover/active/loading/disabled をコンポーネント単位で定義

## 5. 成果物要件
- Figmaページ構成:
  - 00_cover
  - 01_wire
  - 02_ui
  - 03_components
  - 04_handoff
- コンポーネント命名規則: `cmp/{type}/{name}/{variant}`
- バリアント設計: size / tone / state
- Dev handoff注釈:
  - spacing token
  - font token
  - color token
  - state差分

## 6. 制約・前提
- 技術制約: 既存PHPテンプレート + CSS/JS構成へ実装可能であること
- 実装優先度: 実績証拠化 > CTA統一 > FV再設計
- 締切: 初稿デザイン受領 2026-04-12

## 8. 最終依頼文（貼り付け用）
以下の要件でFigmaデザインを作成してください。目的は「3分で評価可能な証拠型ポートフォリオ」のMVP構築です。対象画面はトップ・実績一覧・実績詳細・問い合わせ。必須要件は、実績詳細の5項目テンプレート（課題/担当範囲/実装/成果/技術）、全ページCTA統一、レスポンシブ（375/768/1280）、アクセシビリティ考慮です。トーンは信頼感重視、青系アクセント、可読性優先。コンポーネントは Header/Nav, CTA Button, Project Card, Project Detail Block, Skill Block, Footer をバリアント付きで設計し、Dev handoffにトークンと状態差分を明記してください。
