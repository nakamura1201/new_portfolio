# 製品仕様正本

最終更新: 2026-04-08

## 1. 仕様目的
採用/発注判断者が、3分以内に実務適合性を評価できる証拠型ポートフォリオを実装する。

## 2. 画面仕様
### 2.1 トップページ
- ファーストビューに以下を必須表示:
  - 職種（フロントエンドエンジニア）
  - 専門領域（例: UI実装、パフォーマンス改善、保守性設計）
  - CTA（実績を見る / 問い合わせる）
- 30秒理解達成を目的に、見出し文を1〜2文へ圧縮

### 2.2 実績一覧ページ
- 代表実績3件以上
- 各カード必須項目: 案件名、概要、技術タグ、詳細遷移

### 2.3 実績詳細ページ
- 必須セクション:
  1. 課題
  2. 担当範囲
  3. 実装内容
  4. 成果（定量/定性）
  5. 使用技術

### 2.4 問い合わせ導線
- ヘッダー/フッター/主要セクションに統一CTA設置
- 1クリックで連絡手段（メールまたはフォーム）へ遷移
- 返信目安を明記

## 3. コンポーネント仕様
- 実績テンプレートコンポーネント
- CTAコンポーネント（配置: header/footer/in-content）
- スキルカテゴリ表示コンポーネント

## 4. 計測仕様
- イベント: EV-01〜EV-10
- 主要計測:
  - first_view_30s
  - decision_action
  - cta_click
  - contact_reach
- プロパティ:
  - session_id, device, referrer, action_type, elapsed_sec

## 5. 非機能仕様
- パフォーマンス: 初回表示3秒以内
- セキュリティ: 出力エスケープ、入力バリデーション
- アクセシビリティ: キーボードで主要導線到達可
- レスポンシブ: 375/768/1280で導線破綻なし

## 6. 受け入れ条件
1. 30秒理解達成率 >= 80%
2. 3分判断達成率 >= 70%
3. CTA到達率 >= 80%
4. 問い合わせ意向率 >= 50%
5. 実績テンプレ必須5項目の充足率 100%

## 7. 変更管理
- 仕様変更時は `doc/02_requirements/change-management/変更履歴.md` を更新する。
