# コードレビュー・スキル (Codex)

このスキルは、外部 AI ツール `codex` を呼び出し、プロジェクト固有の高品質なコードレビューを行う手順を定義します。

## 1. 概要

本プロジェクトでは、コードの品質担保に `codex` コマンドラインツールを使用します。
通常の Lint ツールでは検出できない、論理的なバグや設計上の改善点を発見するために使用します。

## 2. 実行手順

エージェント（またはユーザー）は以下の手順でレビューを実行します。

1. **ターミナルを開く**
   プロジェクトルートディレクトリでターミナルを開きます。

2. **Codex の起動**
   以下のコマンドを実行します。

   ```bash
   codex
   ```

3. **スキルの呼び出し**
   Codex のインタラクティブモード内で、以下のスキルコマンドを実行します。

   ```text
   /skills review-improve-tools
   ```

4. **レビュー指示**
   レビューしたい対象（ファイル名や実装内容）を伝えます。
   例: 「`index.php` のセキュリティ脆弱性をチェックして」

## 3. レビュー観点

Codex には以下の観点でのチェックを依頼してください。

- **セキュリティ**: SQL インジェクション、XSS 対策がされているか（`htmlspecialchars`の使用など）。
- **パフォーマンス**: 無駄な DB クエリや重い処理がないか。
- **可読性**: 変数名がわかりやすいか、単一責任の原則に従っているか。
- **FLOCSS/BEM 準拠**: CSS ファイルの場合、プロジェクトのルールに従っているか。

## 4. 自動化スクリプト（将来用）

将来的に非対話モードがサポートされた場合、以下のようなスクリプトで自動化可能です。
`scripts/review.bat`:

```batch
codex --run "/skills review-improve-tools --target %1"
```
