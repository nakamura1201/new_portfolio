# 納品・ビルドワークフロー

作業の最終段階として、成果物をパッケージングします。
`/bundle-assets` コマンドで実行します。

## 1. ビルドの実行

Vite 環境の場合、以下のコマンドを実行します。

```bash
npm run build
```

エラーが発生した場合は、内容を解析し修正してください。

## 2. アセットの最適化

`.agent/skills/interactive_motion/SKILL.md` のパフォーマンス基準を満たすため、画像を最適化します。

- [ ] **画像圧縮**: `node compress-images.mjs` を実行（存在する場合）。
- [ ] **不要ファイル削除**: `dist` フォルダから `.map` ファイルや `.DS_Store` を削除。

## 3. 成果物のパッケージング

指定された納品形式に合わせてファイルをまとめます。

1. `dist` ディレクトリの内容を確認。
2. 必要であれば `dist` ディレクトリ全体を `release_YYYYMMDD.zip` に圧縮。

## 4. 最終確認

- [ ] 圧縮ファイルのサイズは適切か？
- [ ] 解凍して正常に閲覧できるか？
